# 校园开源资源库

> 打破信息壁垒，共享课程攻略。

## 📖 简介

本仓库旨在汇聚校园内各专业课程的优质学习资源，包括但不限于：

- **课件** — 课程讲义、幻灯片
- **笔记** — 个人/集体整理的课程笔记
- **试卷** — 历年考试真题、模拟题
- **作业** — 课程作业、实验报告
- **项目** — 课设、大作业、开源项目
- **参考书目** — 课程推荐教材、电子书
