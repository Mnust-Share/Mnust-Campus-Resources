# 贡献指南

欢迎贡献！请遵循以下规范以确保仓库整洁有序。

---

## 📁 目录命名规范

| 规则 | 说明 |
|------|------|
| **学院目录** | 使用完整中文名称，如 `信息工程学院`、`计算机学院` |
| **课程目录** | 使用课程全称（中文），如 `数据结构`、`操作系统` |
| **分类目录** | 统一使用：`课件`、`笔记`、`试卷`、`作业`、`项目`、`参考书目` |

> 💡 **尚未有你学院的目录？** 欢迎自行创建！请遵循：`学院/学院名称/课程名称/资源分类/`

## 📄 文件命名规范

| 文件类型 | 命名示例 | 说明 |
|----------|----------|------|
| 课件 | `第1章-绪论.pptx` | `章节-标题.扩展名` |
| 笔记 | `第1章-绪论-笔记.md` | `章节-标题-笔记.扩展名` |
| 试卷 | `2024-期末考试-A卷.pdf` | `年份-考试类型-卷号.扩展名` |
| 作业 | `实验1-线性表-答案.md` | `实验号-内容-类型.扩展名` |
| 项目 | `学生管理系统-源码.zip` | `项目名称-类型.扩展名` |
| 参考书目 | `数据结构-C语言版.pdf` | `书名-版本.扩展名` |

### 命名通用规则

1. **使用中文命名**，便于检索
2. **单词之间用短横线 `-` 连接**
3. **不允许使用空格**（可用 `-` 或 `_` 代替）
4. **不允许出现特殊字符**：`\ / : * ? " < > |`
5. **大小写敏感**，请保持统一风格

## 🚀 贡献流程

### 方式一：通过 GitHub Pull Request

1. **Fork** 本仓库
2. **Clone** 你的 Fork 到本地
3. 按上述规范创建或更新目录与文件
4. **Commit** 并 **Push** 到你的仓库
5. 提交 **Pull Request**

### 方式二：直接提交 Issues

如果你不熟悉 Git 操作，也可以通过提交 Issue 的方式分享资源，管理员会协助整理。

## ✅ PR 检查清单

提交 PR 前请确认：

- [ ] 目录结构遵循本指南的命名规范
- [ ] 文件命名符合规范，不使用空格或特殊字符
- [ ] 不包含侵权或受版权保护的内容
- [ ] 已阅读并同意许可协议

## ⚠️ 注意事项

- **不要提交** 包含个人隐私信息（学号、身份证号、手机号等）的文件
- **不要提交** 病毒、恶意代码或违反法律法规的内容
- **大文件**（>50MB）建议提供网盘链接而非直接上传
- **同一份资料** 请勿重复提交到多个课程目录
